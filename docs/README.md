# Documentation Index

只有根目录 [README](../README.md)、[AGENTS](../AGENTS.md)、[Agent Current Truth](../.agents/AGENT2READ.md) 和 [`current/`](current/) 中明确标记为当前状态的文档可以定义 Current Truth。Fresh live evidence 可以推翻旧结论，但必须随后同步更新这些当前入口。架构、证据、事故、决策、参考和历史计划不能单独把旧状态提升为当前 blocker。

- [`current/`](current/)：当前竞赛路线图和正在生效的工程状态。
- [`architecture/`](architecture/)：系统与 lifecycle 架构，不承担进度状态。
- [`evidence/`](evidence/)：已接受里程碑的紧凑验证证据。
- [`incidents/`](incidents/)：已解决或历史故障、根因和可复用诊断经验。
- [`decisions/`](decisions/)：已接受工程决策及其边界。
- [`reference/`](reference/)：外部权威材料，包括[正式参赛指南](reference/competition-guide-2026.pdf)。
- [`runbooks/official-asset-metadata-calibration.md`](runbooks/official-asset-metadata-calibration.md)：官方模型标定场的离线与受控 T1 元数据操作手册；不定义 Current Truth。
- [`superpowers/`](superpowers/)：设计和实施计划记录；保留原位置，不作为 Current Truth。
